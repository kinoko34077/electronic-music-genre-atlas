# Electronic Music Genre Atlas

**PUBLIC research project, as requested 2026-11-14. IN PROGRESS — NOT 510 verified songs.**

Fifty-one fixed historical and emerging electronic-music genre/style comparison bins; 510 target songs (5 formative + 5 originally released 2022–2026, per bin) subject to explicit evidence-based classification exceptions.

Record category history, music characteristics, genealogy, dated sources that explicitly name each song, separate A/B/C evidence strength, and official **song-specific** original recording URL; never treat search/playlists, genre tags alone, reuploads, outdated versions or reviral classics as verified contemporary tracks. No mass fake-filling.

Use parent Issue and initial specification as research and verification contract. Existing chat prototype for 2026-11-14 has 16 populated candidates only; historical counts 343/240 are not source-validated.
